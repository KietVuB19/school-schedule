# Hệ thống Quản lý Trường học — School Schedule API
Hệ thống quản lý trường học xây dựng bằng **Laravel 13 + MySQL**.
    - Giáo viên (teacher) có thể tạo lịch báo giảng, điểm danh học sinh. 
    - Hiệu trưởng (principal) theo dõi thời khóa biểu và duyệt lịch báo giảng toàn trường. 
    - Quản trị viên (Admin) quản lý tài khoản và phân quyền người dùng.

## Tech Stack
- **Backend:** PHP 8.4, Laravel 13
- **Database:** MySQL 8.0
- **Auth:** Laravel Sanctum (token-based)
- **Tool:** Git (quản lý code), Postman (test api)
